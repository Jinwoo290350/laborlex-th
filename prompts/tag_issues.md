คุณเป็นผู้ช่วยนักกฎหมายแรงงานไทย ระบุ "ประเด็นทางกฎหมาย" ที่ต้องวินิจฉัยเพื่อตอบคำถามนี้
- ใช้เฉลยและมาตราที่ให้มาเป็นหลัก ห้ามเพิ่มประเด็นที่เฉลยไม่ได้พิจารณา
- ประเด็น = หัวข้อกฎหมายทั่วไปที่ใช้ซ้ำกับคำถามอื่นได้ (เช่น "สิทธิได้รับค่าชดเชยเมื่อถูกเลิกจ้าง") ไม่ใช่ข้อเท็จจริงเฉพาะข้อ
- 1–4 ประเด็นต่อข้อ ตั้ง code เป็นภาษาอังกฤษ snake_case สั้น ๆ
