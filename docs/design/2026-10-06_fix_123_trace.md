Statute check (DB text, LRA2518:123:1:(3) and 31:1:(3)): the order "ต้องมิได้ออกเพื่อขัดขวางมิให้บุคคลดังกล่าวดำเนินการเกี่ยวกับข้อเรียกร้อง" is a
real condition, so the motive fact is relevant. The model answer treats the transfer that follows the agreement and the
employee's own stated wish as a lawful order (the conflict is not treated as obstruction), and concludes: not protected,
but cannot be dismissed at once without a written warning.

Fix (#17): sub-elements a refused · b per agreement · c employee asked/consented · d facts show the order aims to obstruct
action on the demand · e written warning or serious case. System: lawful order refused = a ∧ (b ∨ c) ∧ ¬d; exception (3) =
that ∧ e. Local tests (`tests/unit/test_element_derive.py`, fail-first): the 2554 pattern → lawful order met, exception
not met (warning missing); refusal alone → not met / unknown; obstruction met → not lawful. **Interpretation of d comes
from this one model answer — needs review.** The ULP (s.121(1)) must_not is not directly addressed; only the E2E will show
whether the draft stops adding it once the element is right.
