# คำถามถึงอาจารย์ (Frank ถามในกลุ่ม LINE)

> หลัก: ถามเฉพาะสิ่งที่ต้องใช้ดุลพินิจทางกฎหมาย และตอบได้ในไม่กี่บรรทัด
> อะไรที่หาได้จากตัวบทหรือเฉลย dev100 ระบบหาเอง (ดูส่วน "ตอบเองแล้ว")

## ต้องถาม (เรียงตามผลกระทบต่อคะแนน)

| # | คำถาม (ส่งได้ทันที) | ใช้ที่ไหน | คำตอบ |
|---|---|---|---|
| 1 | ถ้าคำถามไม่ระบุวันเกิดเหตุ ให้ตอบตามกฎหมายปัจจุบัน และถ้ามาตราเคยถูกแก้ไขให้หมายเหตุหลักเดิมสั้น ๆ — ตรงกับที่อาจารย์ใช้ตรวจไหมครับ | ทุกคำตอบ (§4.4) | |
| 2 | ถ้ากฎหมายลูก (กฎกระทรวง/ประกาศ) กำหนดเกินกรอบที่กฎหมายแม่ให้ไว้ ระบบจะแสดงทั้งสองฉบับ แจ้งว่า "อาจขัด" และยึดกฎหมายแม่ — อาจารย์เห็นด้วยไหมครับ | hierarchy rule | |
| 3 | สินจ้างแทนการบอกกล่าวล่วงหน้า ระบบอ่าน ม.17 วรรคสอง + ม.17/1 ว่า: เลิกจ้างวันที่ X โดยไม่บอกกล่าว → จ่ายค่าจ้างตั้งแต่ X ถึง "กำหนดจ่ายค่าจ้างคราวถัดไปหลังกำหนดจ่ายคราวแรกที่ถึงหลัง X" และไม่เกิน 3 เดือน ถูกไหมครับ (ตัวอย่าง: จ่ายเงินเดือนทุกสิ้นเดือน เลิกจ้าง 10 มี.ค. → จ่ายถึง 30 เม.ย.) | `calc.notice_pay` | |
| 4 | ตรวจ taxonomy 28 ประเด็น (ไฟล์แนบ) — ติ๊ก ✓/✗ ต่อประเด็นและองค์ประกอบ + ตอบข้อเสนอ 4 ข้อใน `docs/review/taxonomy_review.md` | spot_issues, check_elements | |

## ตอบเองแล้ว (ไม่ต้องถาม)
- **ตัวหารค่าจ้างรายเดือน → รายวัน/รายชั่วโมง**: ม.68 วรรคหนึ่ง (`LPA2541:68:1`) "ค่าจ้างรายเดือนหารด้วยผลคูณของสามสิบและจำนวนชั่วโมงทำงาน…ต่อวันโดยเฉลี่ย" และเฉลย dev035/dev039 คำนวณ "× 10 เดือน (300 วัน)" สอดคล้องกัน
- **ป.พ.พ. ไม่อยู่ในโฟลเดอร์**: ดึงฉบับปรับปรุงล่าสุดจากกฤษฎีกาแล้ว (เฉพาะส่วนที่เกี่ยวกับแรงงาน)
- **พ.ร.บ.แรงงานสัมพันธ์ / กฎกระทรวงฉบับที่ 1 / กฎกระทรวง OT 2568 / พ.ร.บ.จัดตั้งศาลแรงงานฯ**: ดึงฉบับปรับปรุงล่าสุดจากกฤษฎีกาแล้ว
