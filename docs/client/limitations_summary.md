# LaborLex-TH — สิ่งที่ระบบทำได้และข้อจำกัดของเวอร์ชันทดลอง

เวอร์ชันสำหรับทดลองใช้ (ตุลาคม 2569)

## สิ่งที่ระบบทำ

- **ตอบตามรูปแบบที่ลูกค้ากำหนด:** คำตอบเบื้องต้น → ประเด็นทางกฎหมาย → กฎหมายที่เกี่ยวข้อง → การปรับบทกับข้อเท็จจริง → ข้อสรุปรายประเด็น → ตารางความเห็นทางกฎหมาย
- **ตัวเลขทุกตัวคำนวณด้วยโปรแกรม ไม่ใช่ AI** (ค่าชดเชย, สินจ้างแทนการบอกกล่าวล่วงหน้า, ค่าจ้างงวดสุดท้าย) พร้อมแสดงวิธีคำนวณและมาตราที่ใช้ทุกขั้น
  - กรณีลูกจ้างหลายคน ระบบแสดงตารางจำนวนเงินแยกรายคนและยอดรวม
- **ทุกการอ้างอิงตรวจย้อนได้:** คลิกที่มาตราหรือคำพิพากษาเพื่อดูข้อความเต็มจากฐานข้อมูล
  - ระบบตรวจทุกการอ้างอิงก่อนแสดงผล จึงไม่อ้างมาตราหรือคำพิพากษาที่ไม่มีอยู่จริง
- **แจ้งการแก้ไขกฎหมาย:** ระบบแจ้งเมื่อมาตราที่อ้างเคยถูกแก้ไข
- **ถามข้อมูลเพิ่ม:** เมื่อข้อเท็จจริงไม่พอ ระบบระบุว่าต้องทราบอะไรเพิ่ม แทนการเดา

## ข้อจำกัดของเวอร์ชันนี้

1. **คำพิพากษาศาลฎีกาที่อ้าง**
   - ฐานข้อมูลมีคำพิพากษาคดีแรงงาน 3,591 เรื่อง
   - การเลือกคำพิพากษามาประกอบคำตอบยังเป็นวิธีเบื้องต้น จึงอาจยังไม่ใช่ฎีกาที่ตรงหลักกฎหมายที่สุดในทุกกรณี และฎีกาบางเรื่องยังไม่มีในฐานข้อมูล
   - การปรับปรุงส่วนนี้เป็นงานลำดับถัดไป
2. **การวินิจฉัยเหตุตามมาตรา 119 รายอนุมาตรา**
   - ระบบตรวจว่าอนุมาตราที่ AI เลือกมีอยู่จริงและอ้างอย่างถูกที่ และคำนวณเงินด้วยโปรแกรมตามผลการวินิจฉัย
   - แต่การวินิจฉัยว่าลูกจ้างเข้าข้อยกเว้นหรือไม่ และเข้าอนุมาตราใด เช่น (1) หรือ (2) ยังเป็นการวิเคราะห์ของ AI ควรตรวจทานในส่วนนี้
3. **หัวข้อย่อยบางหัวข้อ** ที่ AI ตั้งชื่ออาจไม่ตรงกับเนื้อหามาตราเสมอไป โดยตัวบทที่อ้างยังถูกต้อง
4. **กฎหมายบางส่วนยังไม่อยู่ในฐานข้อมูล** เช่น ป.พ.พ. ลักษณะห้างหุ้นส่วน
   - คำถามเรื่องความรับผิดของหุ้นส่วนผู้จัดการ ระบบจะตอบโดยไม่มีตัวบทรองรับในส่วนนั้น
5. **การใช้งาน**
   - ใช้เวลาประมาณ 2–3 นาทีต่อคำถาม
   - ลิงก์ทดลองอาจเปลี่ยนเมื่อมีการเริ่มระบบใหม่
   - คำตอบเป็นข้อมูลประกอบการพิจารณา ไม่ใช่คำปรึกษาทางกฎหมาย
